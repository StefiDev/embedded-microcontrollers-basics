# Lab 1: Blinking LEDs

## Objective
Build a prototype using an Arduino and a breadboard that features two alternating blinking lights.

## Requirements

### Basic Implementation (Good)
- Create a circuit with two LEDs.
- Program the Arduino to make the LEDs blink in an alternating pattern (one on while the other is off).

### Advanced Implementation (Very Good / Excellent)
1.  **Variable Timing**: Change the duration for which each light is turned on and off.
2.  **Dead Time**: Add a delay between the switching of the lights so that there is a short period where **both** lights are off before the next one turns on.
