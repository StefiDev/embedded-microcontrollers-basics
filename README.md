# Embedded Engineering Projects

This repository contains my embedded engineering projects from the 1st Term and the beginning of the 2nd Term.

## Repository Structure

- `src`: Source code for all projects.
- `lib`: Shared libraries.
- `docs`: Documentation, images, and schematics.

## Project List

> [!NOTE]
> Most projects in this repository were created and simulated using **Tinkercad**.
> The **07_First_Term_Project** was developed using real software and hardware.

### First Term
1.  [**01_Lab1**](src/01_Lab1): Introduction to Arduino GPIO.
2.  [**02_Lab2**](src/02_Lab2): Advanced GPIO and Timing.
3.  [**03_UART_Lab_1**](src/03_UART_Lab_1): UART Communication Basics.
4.  [**04_UART_Lab_2**](src/04_UART_Lab_2): Advanced UART.
5.  [**05_SPI_Lab_1**](src/05_SPI_Lab_1): SPI Protocol Experiments.
6.  [**06_I2C_Lab_1**](src/06_I2C_Lab_1): I2C Protocol Experiments.
7.  [**07_First_Term_Project**](src/07_First_Term_Project): Final project for the first term (Smart Home Controller).

### Second Term
8.  [**08_DC_and_Servo**](src/08_DC_and_Servo): Motor control with DC and Servo motors.
