# Embedded Engineering Projects

This repository contains my embedded engineering projects from the 1st Term and the beginning of the 2nd Term.

## Repository Structure

- `src`: Source code for all projects.
- `lib`: Shared libraries.
- `docs`: Documentation, images, and schematics.

## Project List

> [!NOTE]
> Most projects in this repository were created and simulated using **Tinkercad**.
> The **07_First_Term_Project** was developed using real software and hardware.

### First Term
1.  [**01_Lab1**](src/01_Lab1) ([Task](docs/01_Lab1/task.md)): Introduction to Arduino GPIO.
2.  [**02_Lab2**](src/02_Lab2) ([Task](docs/02_Lab2/task.md)): Advanced GPIO and Timing.
3.  [**03_UART_Lab_1**](src/03_UART_Lab_1) ([Task](docs/03_UART_Lab_1/task.md)): UART Communication Basics.
4.  [**04_UART_Lab_2**](src/04_UART_Lab_2) ([Task](docs/04_UART_Lab_2/task.md)): Advanced UART.
5.  [**05_SPI_Lab_1**](src/05_SPI_Lab_1) ([Task](docs/05_SPI_Lab_1/task.md)): SPI Protocol Experiments.
6.  [**06_I2C_Lab_1**](src/06_I2C_Lab_1) ([Task](docs/06_I2C_Lab_1/task.md)): I2C Protocol Experiments.
7.  [**07_First_Term_Project**](src/07_First_Term_Project) ([Task](docs/07_First_Term_Project/task.md)): Final project for the first term (Smart Home Controller).

### Second Term
8.  [**08_DC_and_Servo**](src/08_DC_and_Servo) ([Task](docs/08_DC_and_Servo/task.md)): Motor control with DC and Servo motors.
